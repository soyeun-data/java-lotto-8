# java-lotto-precourse

# 구현할 기능 목록

## 핵심 기능
- [ ] 입력된 금액/1000 을 계산한 값 만큼 로또 발행
- [ ] 1 ~ 45 사이의 값으로 중복되지 않는 6개의 숫자 뽑기
- [ ] 로또 수량과 발행한 로또 숫자를 오름차순으로 출력
- [ ] 입력된 당첨 번호를 쉼표(,)로 분리
- [ ] 발행한 로또 번호와 입력된 당첨 번호를 비교하여 당첨 기준에 맞는지 확인
- [ ] 각 당첨 기준에 해당되는 개수와 수익률 계산 후 출력

## 입력
- [ ] 로또 구입 금액 및 안내 메시지("구입금액을 입력해 주세요.")
- [ ] 당첨 번호 및 안내 메시지("당첨 번호를 입력해 주세요.")
- [ ] 보너스 번호 및 안내 메시지("보너스 번호를 입력해 주세요.")
- 입력 예외
  - [ ] 입력된 금액이 숫자가 아닐 경우
  - [ ] 1000원 단위로 나누어 떨어지지 않는 경우
  - [ ] 입력된 당첨 번호 및 보너스 번호가 1 ~ 45 사이의 숫자가 아닐 경우

## 출력
- [ ] 로또 수량("OO개를 구매했습니다.")
- [ ] 로또 번호 출력(오름차순으로 정렬)
- [ ] 당첨 내역 출력
- [ ] 수익률은 소수점 둘째 자리에서 반올림
- [ ] 예외 상황 시 에러 문구 출력. 에러 문구는 "[ERROR]"로 시작
